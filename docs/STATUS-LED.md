# UFI003 状态灯

由独立的 `nassimhub-status-led.service` 控制物理蓝、绿、红灯，不修改电话、短信、音频服务，也不直接访问基带。

| 状态 | 灯效 |
| --- | --- |
| 蜂窝已注册，包括建立数据连接时 | 绿灯常亮 |
| 等待注册、无 SIM、SIM 锁定、ModemManager 暂不可用 | 蓝灯慢闪：亮 0.3 秒、灭 1.7 秒 |
| ModemManager 连续三次明确报告 failed | 红灯慢闪：亮 0.3 秒、灭 1.7 秒 |

每 10 秒读取一次 ModemManager 缓存状态。绿灯表示蜂窝注册成功，不表示 NAS 已配对、互联网可达或语音媒体已就绪。状态查询失败不当作硬件故障；恢复注册后自动恢复绿灯。不同状态仅亮一种颜色，不再让存储读写触发物理红灯；不修改 `mmc0::` 逻辑灯。

可以将 `/etc/nassimhub/status-led.conf` 的 `NSH_STATUS_LED_ENABLED` 改为 `no`，然后重启服务，关闭指示灯。停止服务也会熄灯。重新启用时改为 `yes` 并重启服务。

源码已加入固件 overlay 和工厂包的开机启用列表。当前设备可独立安装脚本、配置和服务，无须刷写系统或重启基带。实际灯色和可见闪烁仍需设备旁的人确认。
